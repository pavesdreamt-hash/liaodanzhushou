    只读保存来源名称、标识、成本、建议售价与库存快照
  4. 第四步：同步网站产品到本机✓
    只读保存可判断的全量网站商品；含上下架与库存状态，不读取图片尚未同步网站产品到本机。

    根据两份当前本机快照逐条人工确认，再保存本机映射
  6. 第六步：核对变化✓
    只读取已确认映射商品的最新网站资料，生成本机差异
