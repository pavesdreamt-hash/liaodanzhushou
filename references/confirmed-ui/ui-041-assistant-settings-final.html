允许自动处理

  • 客户表达购买意向并明确商品后，根据网站实际售价主动报价。
  • 向客户收集姓名、电话号码和详细配送地址。
  • 客户询问库存时，只回答“有货”或“无货”，不透露数量。
  • 确认无货时明确说明暂时无法发货，并暂停后续自动处理。

必须转人工

  • 优惠、批发价、改价或继续议价。
  • 商品推荐、替代商品和最终订单确认。
  • 向客户发送发货、签收或回款状态。
  • 未设置规则的任何自动化操作。
